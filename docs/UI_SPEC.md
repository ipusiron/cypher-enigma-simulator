## 4. 設定エリア（Settings）

### 4.1 プラグボード（Plugboard）

- ON/OFFトグル（デフォルト: OFF）
- テキスト入力: 文字ペア指定（例: `A-B, S-Z`）
- 補足: 未指定文字はそのまま通過

### 4.2 スクランブラー（Scrambler 1-3）

- ドラッグハンドル（☰）でドラッグ&ドロップ順序変更可能
  - 並び替えても元のラベル番号（Scrambler 1, 2, 3）は維持される
  - 処理順序は画面上の左から右の順序に従う
- ON/OFFトグル
  - Scrambler 1: デフォルトON
  - Scrambler 2, 3: デフォルトOFF
- プリセット選択:
  - カスタム
  - Enigma I〜V
- 配線入力（26文字）
- 開始位置（A-Z、デフォルト: A）
- ノッチ設定
  - ON/OFFトグル（デフォルト: ON）
  - 位置入力（A-Z、デフォルト: Z）
  - ONの場合: このスクランブラーが設定位置を超えると**次のスクランブラー**が1回転
  - OFFの場合: 26回で次段が1回転（従来動作）
  - 注意: 最後のスクランブラーのノッチは効果がない（後続がないため）

### 4.3 リフレクター（Reflector）

- ON/OFFトグル（デフォルト: ON）
- プリセット選択:
  - カスタム
  - Reflector B（デフォルト）
  - Reflector C
- 配線入力（26文字）
- ON: リフレクター往復経路
- OFF: 順方向／逆方向を分ける直通実験
- カスタム配線は置換・自己逆写像・固定点なしを検査

### 4.4 モード切替（Mode）

- ラジオボタン
  - 暗号化（順方向）: デフォルト
  - 復号（逆方向）
- リフレクターON: どちらも同じ往復操作
- リフレクターOFF: 暗号化は順方向、復号は逆方向
- スクランブラーはどちらも左へ回転

## 12. 解析支援タブ

### 12.1 概要

既知平文攻撃機能を提供。スクランブラーの配線はわかっているが、初期位置が不明な場合に使用。

結果は既知文字と一致する候補であり、正解や鍵全体の復元を証明しない。

### 12.2 設定エリア（独自）

解析支援タブは独自の設定を持つ（メインタブとは独立）:
- プラグボード（ON/OFFトグル＋ペア入力）
- スクランブラー 1-3
  - ON/OFFトグル
  - プリセット選択＋配線入力
  - ノッチ設定（ON/OFFトグル＋位置入力）
  - ドラッグ&ドロップで順序変更可能（ラベル番号は維持）
- リフレクター（ON/OFFトグル＋プリセット選択＋配線入力）

### 12.3 入力エリア

#### 暗号文入力
- 複数行テキスト入力
- 最大200文字
- ASCII文字のみ許可（全角文字ブロック）
- 入力時に既知平文グリッドを自動生成

#### 既知平文グリッド
- 暗号文の各アルファベットに対応する1文字入力欄を横並びで表示
- 非アルファベット文字は表示のみ（入力欄なし）
- 空欄は「不明」を意味
- 複数の断片的な既知平文を入力可能
- キーボードナビゲーション（Tab, 矢印キー, Backspace）対応

### 12.4 探索実行

- 探索空間表示（26^n 通り）
- 「探索実行」ボタン
- 実行中だけ表示する「探索を中止」ボタン
- エラーメッセージ領域
- 確認済み件数／全件数／進捗率／一致件数とプログレスバー
- 64通りごとに画面操作を受け付ける。中止時は確認済み範囲だけの途中結果と明示
- 既知文字を入力位置の左から1文字ずつ追加した場合の、追加前・追加後・除外件数を表で表示
- 絞り込み表はモバイルで内部横スクロールとし、ページ全体を横へ広げない

### 12.5 結果表示

各候補について以下を表示:
- スクランブラー初期位置（例: A-B-C）
- 復号結果全文
- 特定理由（どの位置でどの文字が一致したか）
- 一致件数は全件を数え、候補カードは先頭100件まで表示
- 処理トレースは`details`を開いたときだけ生成
- 「設定に適用」ボタン → 適用確認モーダル → メインタブに反映

## 13. モデル比較タブ

### 13.1 入力と設定

- 入力: A-Zのみ、最大40文字
- ローター順序: 左・中・右へI〜Vから重複なく選択
- 各ローターの開始位置とリング設定: A〜Z
- 反射板: B/C
- 比較タブの設定はメインタブの設定と独立し、永続化しない

### 13.2 サンプルと実行

| ボタン | 設定と動作 |
|--------|------------|
| 既知ベクトル（AAAAA） | I-II-III、開始AAA、リングAAA、反射板Bを設定して比較 |
| ダブルステップ例（ADU） | I-II-III、開始ADU、リングAAA、反射板B、入力AAAを設定して比較 |
| 比較する | 現在の入力と設定で両モデルを実行 |

### 13.3 結果

- Cypher向け簡略モデルとEnigma I教育サブセットの全文出力
- 異なる出力文字数
- 選択リングとAAAリング基準の相違文字数
- 打鍵ごとの入力、位置、回転理由、両モデルの出力表
- ダブルステップ行を背景色と太字で強調
- モデル境界表と根拠資料を表示
- 横長の表は内部横スクロールとし、ページ全体を広げない

### 13.4 表示上の限界

- 教育サブセットはプラグボード、機種差、実運用の鍵手順を扱わない
- 「完全な実機再現」ではなく、比較対象の境界をタブ冒頭と根拠資料に明記

## 15. UI設計方針

- 教育・検証重視
- 冗長ログを許容
- セキュリティ: 全入力をサニタイズ
- 320〜414pxは1列、600px以上は2列、900px以上は3列
- モデル比較のローター・リング設定もモバイルは1列、600px以上は3列
- 操作要素は原則40px以上、ドラッグハンドルは44px
- タブは中央揃え、キーボード操作とフォーカス表示に対応
- 全画面、動的エラー、処理トレース、探索結果を日英切り替え
